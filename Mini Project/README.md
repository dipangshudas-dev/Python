# Emoji Converter

This is a basic Python mini-project that takes user input and converts common text emoticons into actual emoji characters. 

## 📝 Description

The program uses simple string replacements (without any loops or if-statements) to find emoticons and replace them with their corresponding emoji characters. It's a great foundational script to understand basic string manipulation (`.replace()`) in Python.

Currently supported emoticons:
* `:)` ➔ 😊
* `:(` ➔ 😔
* `:D` ➔ 😀
* `;)` ➔ 😉

## 🚀 How to Run

1. Open your terminal or command prompt.
2. Navigate to this project folder.
3. Run the script using Python:

```bash
python emojiConverter.py
```

4. Type a message like `Hello :)` when prompted and hit enter to see the result!
