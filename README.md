The code in this repository is organized chronologically by day. Each folder represents a day of learning and contains the scripts, exercises, projects, and concepts I explored on that specific day.

Typical structure:
- `Day_01/`
- `Day_02/`
- `Day_03/`
- `Day_04/`
- `Day_05/`
- `Mini Project/`
